凑单金额计算规则

本稿补充凑单助手的金额口径、计算方式和信息来源。范围为同店凑单，普通用户包含普通新客，不增加会员和优惠券规则。

1. 金额口径

金额 用途 本版口径 待业务确认
商品价格 展示、筛选、本次加购 当前规格单价，含配置的付费规格与加料 普通折扣、数量是否改变单价
起送统计金额 差额、进度、达标判断 本店商品合计，不含包装费、配送费 折前／折后、加料及包装是否计入
最终应付 结算 助手不另行计算 以结算结果为准

起送统计的业务口径尚需确认。当前版本按店内商品金额计算；接入时需要明确商品展示价格与起送统计金额是否相同。

2. 金额计算

金额用整数分计算，显示为元，最多保留两位小数。

  • 单行金额 = 当前规格单价 × 数量。
  • C = 本店实际购物车商品行金额之和。
  • D = 助手已勾选商品行金额之和。
  • P = C + D，为预览金额；其他门店不参与。
  • T为起送门槛；差额 G = max(0, T − P)。
  • T > 0时，进度 = min(100%, max(0%, P ÷ T × 100%))。
  • 有效T = 0表示无金额门槛；缺失、负数或非数字不能按0处理。

P ≥ T且购买校验通过才能提示“加购后可达起送价”。预览达标不代表实际加入成功。有有效选择即可确认加购，不要求一次凑满。成功后按实际购物车重算，仍不足时保留该店入口，实际达标后才移除。

3. 筛选与推荐

筛选按当前规格单件价，不按多杯小计。边界为：低于5元、5≤价格<10、10≤价格<15、15≤价格<20、20≤价格<25、价格≥25。5元归5–10，25元归25元及以上。 推荐不计算最优组合：可购买商品优先；其中一件能补足打开助手时差额的商品按价格升序优先，其余保留目录顺序。操作期间固定顺序，避免商品跳动；重新打开可按最新购物车排序。后续可以按实际业务需求进行补充和推荐顺序调整。

切换筛选保留选择，被隐藏的已选商品仍计入D。“自己选”清空未提交草稿。无价位匹配商品时商品区留空；有匹配商品但受限时保留置灰行和原因。

4. 重算和提交

触发 处理
勾选／取消、增减数量、改规格 更新D、P、G和进度，不改实际购物车
切换筛选 只改变可见列表，不改金额和选择
实际购物车变化 更新C，重新校验草稿和金额
加购成功 按实际写入结果更新C，清除已提交草稿，避免重复累计
明确失败且确认未写入 保留草稿和原购物车，允许重试
超时、结果未知 先核对实际结果，不重复提交整批商品
单价或门槛缺失 不用0补值，不承诺差额或达标

确认前价格／规则变化时应更新金额并让用户重新确认，当前原型未实现真实动态价格核对，同规格合并时沿用原购物车行单价。

5. 需要的信息和来源

以下是需求信息。

信息 用途 预期来源
门店标识、门槛及统计口径 按店计算 门店／交易业务确认；演示为本地配置
购物车商品、规格、数量及起送统计金额 确定C 购物车能力；演示为浏览器本地数据
候选商品当前规格价格 展示、筛选、计算D 商品与价格能力；演示为本地配置
单品／组合是否可加、受限原因 控制加号与确认 购买规则校验；不通过价格或重量猜测
草稿选择、规格、数量 管理未提交内容 用户本次操作生成
写入结果、最新购物车 判断实际成功 购物车写入与核对能力，真实方式待确认
商品与价格版本或更新时间 识别变化 与业务、研发确认可提供方式

6. 算例

起送17元，实际已有柠檬水5.20元：差额11.80元，进度30.59%。勾选12元商品后，草稿12元、预览17.20元、差额0、进度100%；确认前实际购物车仍是5.20元。取消勾选恢复原差额。确认成功后实际购物车17.20元，草稿清零。

其他门店即使已有20元也不减少本店差额。金额够但组合校验失败仍不可确认加购。

7. 定稿前待确认

  1. 起送按折前还是折后统计，规格差价、加料、包装费是否参与。
  2. 数量变化是否影响价格，折扣限份后能否原价购买。
  3. 门槛是否随配送方式、时段或活动变化。
  4. 商品、价格、购买限制能否提前取得并在提交时重新校验。
  5. 批量加购是否可能部分成功以及如何核对实际写入结果。

接口取得方式在接入前确认；本次范围不涉涉及会员、优惠券和配送业务。
