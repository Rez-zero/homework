原型用户路径走查

版本：V0.9.2｜日期：2026-11-01

本轮走查围绕选购、凑单、购物车整理和进入订单确认，覆盖正常完成与返回调整两类操作共11组路径通过；包含360px、390px手机宽度，未出现页面脚本错误。

1. 发现与修复

问题 复现路径 修复后表现
未选中商品保留旧数量，导致误判不可加购 在助手中将黑糖奶茶加至3杯，取消选择；普通选购加入1杯，再打开助手 未选商品按新增1杯判断可购买状态；重新选择从1杯开始，允许继续增量
删除门店后订单确认序号残留 三店达标，进入确认并查看第3单；返回删除一家，再进入确认 从第1单开始显示“订单1/2”，与实际门店数一致
空购物车缺少明确的返回选购入口 按店删除最后一家店 空状态提供“返回选购”，点击后回到商品页，可继续加购

2. 已验证路径

路径 验证内容 结果
普通选购 选商品、改规格、加购、达到起送、进入订单确认并返回 通过
助手草稿 多选、取消、改规格、增减数量、切换筛选、关闭重开、自己选清空 通过
分次凑单 未满起送时确认加购、继续凑单、实际达标后移除入口，刷新保留购物车 通过
多店凑单 三店分别不足；切换分类后仍定位正确门店；依次完成后入口3→2→1→0 通过
按店删除 取消不变、确认仅删除目标店、保留其他店，删空后返回选购 通过
购买限制恢复 不可加状态置灰；减少购物车数量后，允许继续加购 通过
规格取消 助手中修改规格后取消，返回助手且未保存变更 通过
全车清空 取消保留全部商品；确认后回到空购物车选购状态 通过
取消后重新选择 旧草稿数量不再误阻断可加购商品，数量从1开始 通过
删除后再次结算 订单确认序号与当前门店数量一致 通过
手机尺寸完整路径 360px、390px宽度下完成加购、凑单、订单确认、按店删除和返回选购 通过

仅验证原型可操作路径，失败、网络超时、异步恢复和性能参数不纳入本次交互通过结论；业务规则和指标效果仍需后续验证。
